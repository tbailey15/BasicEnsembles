# Basic Ensembles

## About

This project compares classification models and ensemble methods using a small moons dataset. The data is made-up classroom data. Each row has two coordinates, x1 and x2, and a class label.

## Files

- BasicEnsemblesDemo.ipynb
- ensemble_moons_demo.csv
- requirements.txt

## Install

```
python -m pip install -r requirements.txt
```

## Run

Open BasicEnsemblesDemo.ipynb and run the cells from top to bottom. Keep the CSV in the same folder as the notebook.

## What I Learned

Different models can make different mistakes. Ensembles combine models. Validation helps choose a model. The final test data should be saved until the end.
